# Changelog

Все заметные изменения проекта документируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- **Упаковка.** Проект объявлен pip/uv-совместимым: `[build-system]` на
  setuptools и явное перечисление пакета `pulse` и корневых модулей в
  `[tool.setuptools]` — работает editable-установка (`uv sync`, `pip install -e`).
- **CI.** GitHub Actions workflow: lint (`ruff check .`), typecheck (`mypy .`)
  и тесты (`pytest -q`) через uv, матрица ubuntu + windows.
- **Dev-группа.** Инструменты разработки (ruff, mypy, pytest) вынесены в
  PEP 735 `[dependency-groups]`.

### Fixed

- **Вывод при пайпе/редиректе.** `run.py` принудительно переключает stdout/stderr
  на UTF-8 и флашит прогресс-принты — прогресс виден в реальном времени,
  кириллица не ломается при не-консольном выводе.

### Changed

- **Типизация.** Закрыт mypy-долг в `pulse/` и `server.py`: TypedDict-описания
  структур (`_PkgMetrics`, `_RepoEdge`, `_SettingsItem`), аннотации вместо
  вывода типов, три обоснованных `cast`; убраны неиспользуемые импорты в
  тестах. mypy теперь исключает runtime-каталог `data/`.

## [0.2.1] — 2026-10-23

### Fixed

- **Честный подсчёт метрик.** TODO считаются только в комментариях, а не в
  строках и идентификаторах; `long_funcs` считается по каждой функции
  отдельно (порог `LONG_FUNC_COG`), а не по файлу целиком; во вложенности
  сложности Python-функций не «теряются» ветвления на входе и `except`.
- **Дубликаты.** Первое вхождение окна больше не помечается как дубликат —
  дубликатом считается только повтор.
- **Coupling.** Имена в корне `src`, являющиеся настоящими пакетами, теперь
  корректно разрешаются как адресуемые модули.
- **Гонки триггеров скана.** Фаза скана занимает атомарно
  (`Status.try_begin`/`end`, CAS под замком) до запуска потоков: повторный
  `/api/refresh` или `/api/backfill` во время скана получает честный ответ
  «занято» вместо 500, второй поток не стартует; `run.py` дожидается скана.
- **Единый набор файлов.** Список исходников worktree берётся из
  `git ls-files` — снапшот и история больше не расходятся в составе файлов.
- **Безопасность статики.** Усилен path-traversal guard раздачи статики
  (`is_relative_to` вместо `startswith`) с регрессионным тестом на
  соседний каталог.

### Added

- **Покрытие тестами.** Набор тестов вырос с 14 до 124: метрики Python/JS,
  дубликаты, coupling, concurrency триггеров, безопасность сервера,
  smoke HTTP, отчёт .md, score/gitstats/analyze.

### Changed

- **Дедупликация JS-метрик и мёртвый код.** JS-парсер не считает управляющие
  конструкции функциями (продолжение); удалён неиспользуемый код
  (`mi_via_radon`, `activity_dates`).
- **Duplication как метрика первого класса** — первое вхождение окна в отчётах.
- **Coupling src/lib/app** — пакетные уровни считаются по реальным пакетам.
- **server.py разнесён на модули**: `report.py`, `events.py`, `staticfiles.py`
  (693 → ~500 строк) с усиленным static-guard.
- **README** уточнён: per-function `long_funcs`, TODO только в комментариях,
  оговорка по JS.

## [0.2.0] — 2026-09-16

### Added

- **Живое автообновление дашборда.** Сервер шлёт события скана по SSE
  (`GET /api/events`); карточки и открытый проект обновляются сами после
  сканирования — без F5. В шапке появился индикатор состояния (зелёная точка /
  «сканирование N/M»); при недоступном SSE фронт автоматически переходит на
  поллинг статуса раз в 30 секунд.
- **Алерты деградации.** У проекта считается дельта скора за 7 дней (`delta7`);
  при падении на порог и больше карточка и шапка проекта получают красный
  бейдж «▼N». Порог настраивается ключом `alerts.score_drop_7d` в
  `config.json` (по умолчанию 5; ключ опционален). На дашборде — фильтр
  «Проблемные».
- **Экспорт отчёта по проекту в markdown.** Кнопка «Экспорт .md» в шапке
  проекта и `GET /api/report?name=&days=`: итог со скором и дельтами,
  подындексы, топ хотспотов, пакеты Ca/Ce/I/A/D с циклами и нарушениями,
  возраст кода, незакоммиченные файлы. Период — 1–365 дней (по умолчанию 30);
  при отличном от 30 периоде хотспоты пересчитываются по git без кэша.

### Changed

- HTTP-сервер переведён с HTTP/1.0 на HTTP/1.1: keep-alive работает,
  все ответы шлют `Content-Length`, соединение ограничено таймаутом 60 с;
  SSE-поток отдаётся стримом без длины.
