# 📡 Code Pulse — дашборд проектов с телеметрией качества

Локальный веб-дашборд всех проектов из `D:\Projects`: живое git-состояние +
график динамики качества кода и архитектуры за месяц. Ноль зависимостей —
чистый Python (stdlib) + один локальный файл Chart.js.

## Запуск

```bash
python run.py
```

Первый запуск: скан всех проектов → бэкфилл истории за 30 дней по git-коммитам
(без checkout, через `git archive`) → открытие `http://127.0.0.1:8787`.
При каждом старте в фоне обновляется живое состояние и пишется ежедневный
снапшот — график достраивается сам.

```
python run.py --rescan          # только живое сканирование, без сервера
python run.py --backfill-only   # только пересчёт истории
python run.py --no-backfill     # не бэкфиллить при первом запуске
python run.py --days 60         # глубина истории
```

Настройки — `config.json`: корневой каталог, исключения, порт, шаг сэмплирования.

## Что измеряется

### Чистый код
- **Когнитивная сложность** (адаптация SonarSource: вложенность, логические
  операторы, тернарники) — по функции и на KLOC;
- **Цикломатическая сложность**;
- **Maintainability Index** (Halstead + CC + SLOC; калиброван по radon, ±3 пункта);
- **Дублирование** — скользящее окно нормализованных строк;
- **LCOM4** — связность методов класса, детектор God Object;
- размеры: god-файлы (≥400 SLOC), длинные функции, TODO/FIXME, тесты/SLOC.

### Архитектура (Clean Architecture / DDD)
- **Ca / Ce** — афферентное и эфферентное зацепление пакетов по графу импортов;
- **Instability I = Ce/(Ca+Ce)** — домен должен стремиться к 0, внешний слой к 1;
- **Abstractness A** — доля ABC/Protocol/abstractmethod-классов;
- **Distance from Main Sequence D = |A + I − 1|** — зоны боли архитектуры;
- **Циклические зависимости** (SCC графа импортов) и нарушения
  «I > 0.5 при Ca ≥ 3».

### Эволюционные (git-аналитика, Your Code as a Crime Scene)
- **Хотспоты** — когнитивная сложность × частота изменений за 30 дней;
- **Временное зацепление файлов** — стабильно меняющиеся одним коммитом;
- **Churn** — +/− строк по неделям;
- **Code age** — доля кода, не менявшегося ≥90 дней (кандидаты в мёртвый код);
- **Межрепозиторное зацепление** — рёбра графа проектов по общим активным дням.

## Экраны

- **Обзор** — карточки проектов: скор 0–100, динамика за месяц (дельта),
  спарклайн, живой git-статус (ветка, dirty, ↑/↓, stash, последний коммит);
- **Граф качества** — force-граф: размер узла = техдолг (SLOC × (100−MI)),
  цвет = динамика за месяц, рёбра = временное зацепление репозиториев;
- **Карточка проекта** — график качества (итог + подындексы) за 30 дней,
  churn по неделям, таблица пакетов Ca/Ce/I/A/D, хотспоты, временное
  зацепление, возраст кода, незакоммиченные файлы.

## Скор качества

Взвесь: MI 25% · архитектура (D, циклы, нарушения) 20% · когнитивная
сложность (на функцию) 20% · дублирование 15% · тесты 10% · TODO 10%.
Все подындексы нормированы в 0–100, снапшоты хранятся в SQLite
(`data/code-pulse.db`) — динамика сравнима между днями.

## История

- **Бэкфилл**: на каждый шаг (по умолчанию 3 дня) берётся ближайший коммит,
  метрики считаются по его дереву (`git archive` → память, без checkout);
- **Снапшоты**: `WORKTREE` обновляется при каждом сканировании, история
  по деревьям накапливается; пустые деревья не сохраняются;
- JS/TS считается приближённо (регэксп + баланс скобок) — динамика корректна,
  абсолютные значения ориентировочные.

## Ограничения

- git-история — только для репозиториев; проекты без git получают живые
  метрики без графа;
- MI откалиброван по radon для Python; для JS используется своя формула;
- исключаются: `node_modules`, `.venv`, `dist`, `build`, минифицированные
  бандлы (средняя длина строки > 250 символов), файлы > 400 КБ.
